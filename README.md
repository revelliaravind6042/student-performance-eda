# 📊 Student Performance EDA

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) on a Student Performance Dataset to uncover patterns, trends, and factors that influence students' exam scores and placement outcomes.

The analysis focuses on understanding the relationship between study habits, previous academic performance, and final exam results using statistical techniques and data visualizations.

---

## 🎯 Objectives
- Clean and preprocess the dataset
- Explore student performance patterns
- Analyze the relationship between study hours and exam scores
- Examine the impact of previous scores on final performance
- Visualize data distributions and correlations
- Generate actionable insights from the dataset

---

## 🛠️ Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📂 Dataset
**Dataset:** Student Performance Dataset

The dataset contains information about:
- Study Hours
- Previous Scores
- Exam Scores
- Placement Status
- Other student-related attributes

---

## 📈 Analysis Performed

### Data Cleaning & Preprocessing
- Checked for missing values
- Verified data types
- Removed inconsistencies

### Exploratory Data Analysis (EDA)
- Study Hours Distribution
- Exam Score Distribution
- Placement Status Distribution
- Average Exam Score by Placement Status

### Correlation Analysis
- Generated correlation heatmap
- Identified relationships among numerical features

### Visualization
- Study Hours Distribution
- Exam Score Distribution
- Previous Score vs Exam Score
- Exam Score by Study Hours
- Placement Status Distribution
- Correlation Heatmap

---

## 📊 Key Insights
- Students with higher study hours generally achieved better exam scores.
- Previous academic performance showed a positive correlation with exam scores.
- Placement status was strongly influenced by student performance.
- Data visualizations helped identify important trends and patterns.
